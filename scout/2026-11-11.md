## [network] wdl25: train the network to predict the score more and the result less

**What.** Every network so far was trained with WDL 0.5: half of the
training target is the game's result, half is the search score written in
the data (kb16.ps1 `-Wdl`, default "0.5", unchanged in every run since
the first commit; never varied). Variant: WDL 0.25, same recipe, seed
20261019, data files and 600 superbatches as Control2, so it is one change
against Control2. Queue line, which the approved script accepts as it is
(`-Wdl` has been in kb16.ps1 since 18 October, before the current
approval): `tools/net/kb16.ps1 | -KingBuckets 8 -Seed 20261019 -Tag wdl25
-Wdl 0.25`. About 5 hours of GPU; the GPU is free (control-s2 finished).

**Why.** Sunday's measurement (scout/2026-11-08.md, section C): across
eight tested networks, how well a network predicts game results has no
relation to how well it plays, and the one that predicts results best
(new-data) plays worst. The search does not use result probabilities; it
compares the evaluations of sibling positions, and the score half of the
target is the signal that carries that (a deep search's verdict, with
little noise per position), while the result half is one noisy sample per
game that mostly reflects what happened forty moves later. If the
result term adds noise to what the search needs, giving it less weight
should sharpen the eval the search sees. Outside-chess form: label noise
reduction; a lower-variance proxy label beats a noisy ground truth
when the two agree on average.

**Before any game (cheap).** Eval-scale check as for the 2048 network:
mean |eval| on the 1504 calibration positions, new/main ratio. Less
result weight can shift the scale (the pruning margins are tuned to
today's scale): if the ratio is outside 0.95-1.05, note it and expect a
re-tune to be part of the verdict, not a reason to stop.

**Test.** 400-game screen, then head-to-head vs Control2 at 8+0.08,
[0, 5] (the new gate: games decide). If it passes, WDL 0.0 next (pure
score); if it fails clearly, WDL 0.75 is the other direction and a cheap
second night.

**Prediction.** Self-play vs Control2 -5 to +6; about 20% to pass [0, 5]
(scaled 0.6x). Kept against rated engines: about 50% (eval-quality
changes have carried over better than search changes).

**Risk.** A score-trained network inherits the data engine's search
blind spots more fully (the result term is what corrects them); endgame
knowledge the search eval lacks may suffer. One GPU night; no script
work; the 600-superbatch Control2 partner already exists, so no second
run is needed for the pair.
