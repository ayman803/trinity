# Test results

One plain-text file per self-play SPRT test run on GitHub Actions
(`sprt-<number>.txt`, the number shown on the Actions page as "#<number>").
From test #10 on, the SPRT workflow writes the file itself when a run
finishes. A run with "Continue from run" reports the combined totals.

Self-play results decide merges, not strength: see ESTIMATES.md for the
calibration against rated engines.
